Tecnologia de Informação-Banco de Dados

O que é um banco de dados?

Qualquer coleção de informações inter-relacionadas.

Para o que são usados?

Usados para armazenar e organizar dados para que possam ser recuperados, gerenciados e atualizados de maneira fácil.

Desafios de um banco de dados

1.Absorção de aumentos significativos no volume de dados
2.Ganrantia da segurança de dados
3.Acompanhamento da demanda
4.Gerenciamento e manutenção do banco de dados e da sua estrutura
